Mono-faction sealed — V2

A declared sealed tournament where every booster holds cards of one faction, drawn from several sets mixed by weight (×0 = excluded … ×3). Runs on make dev (API :8080, Vite :5173) + altered-dev-environment, with the lot 1 setup: accounts, bob moderator, carol (see group 0 of docs/tournaments/acceptance-user-tournaments.html).

Tick ✓ or ✗ on each step. The ✗ button opens a text field where you can paste screenshots (Ctrl+V). Copy the recap from the tab at the top. The state is kept in this browser (IndexedDB), apart from the lot 1 page’s.

Steps marked auto are replayed by the Playwright suite (make e2e, tests/e2e) on its own card fixtures: no need to run them by hand. An “auto (partial)” badge keeps a manual part: hover it to see which. The “Manual only” filter shows the steps without a badge and the partial ones.
