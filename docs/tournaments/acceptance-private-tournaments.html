Private tournaments and the share box — V4

A declared tournament can be private: it is then listed in Upcoming / Ongoing only to its organizer, the players who have a pool on it and the moderators. Its page, its pool creation and the BGA path work exactly as for a public one (“private” hides, it does not protect). Every tournament page also gets a share box: the link, Copy, “Share…” (native share sheet) and a QR code generated in the browser; the Lobby’s QR code is generated locally too. Runs on make dev (API :8080, Vite :5173) + altered-dev-environment, with the lot 1 setup: accounts, bob moderator, carol (see group 0 of docs/tournaments/acceptance-user-tournaments.html).

A phone cannot reach localhost: locally, scanning a QR code only shows the link it holds. Opening it from a phone (and the phone share sheet) is checked on preprod, in K.

Tick ✓ or ✗ on each step. The ✗ button opens a text field where you can paste screenshots (Ctrl+V). Copy the recap from the tab at the top. The state is kept in this browser (IndexedDB), apart from the lot 1, V2 and V3 pages’.

Steps marked auto are replayed by the Playwright suite (make e2e, tests/e2e) on its own card fixtures: no need to run them by hand. An “auto (partial)” badge keeps a manual part: hover it to see which. The “Manual only” filter shows the steps without a badge and the partial ones.
